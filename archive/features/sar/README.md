# SAR and Disaster Rubble Sensing Archive

The following crates and harnesses were isolated and moved here as part of the transition to **Syntropic Sense** (ambient in-home sensing for dementia and cognitive care):

- `harness-wifi-densepose-sar/`: SAR metaharness, flywheel, and swarm agents
- `wifi-densepose-sar/`: RF tomography backprojection research crate
- `wifi-densepose-mat/`: Multi-target disaster survivor detection and triage crate

These components are preserved for historical reference and future specialized disaster search-and-rescue applications.
