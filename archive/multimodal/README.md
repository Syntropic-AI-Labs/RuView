# Non-RF Multi-Modal & Synthetic Vision Archive

The following non-RF multi-modal integrations and synthetic visual teacher pipelines were archived to ensure **Syntropic Sense** maintains a strict 100% camera-free, zero-PII posture backed by RF beamforming / CSI physical-layer privacy (PrivShield / VEIL):

- `integrations-iphone-lidar/`: Native iOS LiDAR sensor bridge and relay
- `scripts-fal-visual-teacher/`: Fal.ai LoRA visual teacher frame extraction and fine-tuning scripts
- `fal-visual-teacher-sample.json`: Synthetic teacher keypoint annotations
- `iphone-lidar.yml`: GitHub Actions CI workflow for iPhone LiDAR
